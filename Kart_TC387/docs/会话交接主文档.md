### 蜂鸣器系统（已封板）

**架构**：CCU60_CH1独立1ms中断 + GPIO软件翻转

**核心经验**（详见`docs/horn_timing_issue_resolution.md`）：
- 主循环周期不可靠（IPS200刷新耗时≈36ms），精确时序必须用硬件定时器中断

## 科目一规则（当前已确认）

场地为室外操场，包含发车区、锥桶绕行区和倒车入库区。

比赛流程：

1. 车模从发车区自动出发。
2. 按比赛给定方向，依次绕行全部锥桶。
3. 到达倒车入库区后完成倒车入库。
4. 入库完成后停车，科目结束。

用户 2026-07-20 补充确认（写入本轮倒库逻辑的依据）：

- **锥桶随机摆放**：每场位置/顺序不固定，但**路线现场手推录制**，随机性由手推轨迹消化，**不需视觉**。
- 绕行方向：上方逆时针、右下逆时针、左下顺时针、中部逆时针。
- 锥桶间距通常 `>3 m`；倒车入库入口宽约 `1.5 m`。
- 车库尺寸：深 `2 m` × 宽 `1.5 m`；采用**直线倒库**（库前对正→回中→直线倒入，非揉库）。
- 倒库流程点位：A=车库前接近/对正点，B=库中心线摆正点，C=库内停车点。
- **A 点 = 录制轨迹终点**（手推到库前对正位停录 `r0`），playback 复现到 A 自停，无需单独按键打点。
- A→B 对正段（约 1.2~1.8 m，B 航向误差 `<3°`）：当前**未单独实现**，按“A 即可直接倒车位”处理，待实车验证是否需要补摆正阶段。
- 倒车减速点 `1.05 m`、停车点 `1.40 m`（车长约 1.3 m），均为估值，**实车微调**。

仍未确认、不得猜测：发车区/赛道尺寸、判罚、入库完成判据和限时。

### 科目一状态机流程（已实现）

```
S1_WAIT_START      START 键下降沿（P20_7 上拉，按下=0）→ playback_start() → CONE_ROUTE
S1_CONE_ROUTE      等 playback 跑完（到 A 点自停）→ GARAGE_APPROACH
S1_GARAGE_APPROACH 等车停稳 → 记里程基准 + 关外环/开内环/方向回中(target_delta=0)/负速 → REVERSE_IN
S1_REVERSE_IN      持续 target_delta=0，里程增量判据：≥1.05m 降慢速(-12)，≥1.40m 刷车收车 → FINISHED
S1_FINISHED        保持无输出
```

**关键设计：倒车不走航向外环**——倒车时前轮打角对车尾是正反馈会发散。改用内环把方向盘按中位 + 负速直倒，短距 1.4m 直线偏差可接受。

14. 验证 A 点是否已对正；若需额外 A→B 摆正，再单开阶段。

**硬件自测（屏幕/按键）**：
15. `KART_HW_TEST=1` 烧录，验证并口 IPS200 显示 + 旋钮计数 + 五向键电平；验证完改回 0。

## 调试速查

- `e0/e1`：速度环；`se0/se1`、`sa<值>`：转向内环；`he0/he1`、`ht<角度>`：航向外环。
- `z`：仅在速度环关闭时清编码器和航位坐标，不清IMU yaw。
- `r1/r0`：录制开/停；`b1/b0`：复现开/停。
- `w<slot>`：存当前 RAM 路径到 Flash 槽位（仅速度环关闭时）；`f<slot>`：从 Flash 读回 RAM。
- `m0/m1/m2/m3`：切换模式 IDLE/科目一/科目二/遥控（切模式统一走 `mission_stop_all()` 停机）。
- **复现正确流程**：`m0` → 摆正车 → `z` → **遥控开机推中/高挡**（ch33=1或2，否则 deadman 急停）→ `b1`。
- VOFA：`ch0/ch1`速度，`ch2`yaw，`ch3~ch6`转向，`ch7~ch10`左右轮，`ch11~ch13`里程/X/Y，`ch19`录制点数，`ch28`遥控在线，`ch33`挡位（0低/1中/2高）。
