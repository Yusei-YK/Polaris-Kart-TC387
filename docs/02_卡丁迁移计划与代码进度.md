# 卡丁迁移计划与代码进度

> 历史阶段计划，不再维护当前进度。当前状态看根目录 `README.md`。

本文档记录当前有效的迁移计划与代码进度。临时会话纪律、上下文防丢失提示和重复路径说明已删去。

## 总目标

完成卡丁快跑科目一的低速稳定底盘平台：

```text
编码器累计路程 + IMU yaw + 前轮角度闭环 + 左右后轮速度闭环 + Mission 状态机
```

短期成功标准：

- 上电默认不输出电机。
- 三路电机能悬空低 PWM 单独控制。
- 左右后轮编码器方向正确。
- 转向绝对编码器 raw 在 `0~4095` 内稳定刷新。
- IMU yaw 可 reset，短时间漂移可接受。
- VOFA 可观察目标、反馈、输出和故障。
- 后轮速度环、前轮角度环、yaw 外环逐步跑通。

## 当前主循环与控制节拍

初始化顺序：

```text
power
encoder
steer_abs
debug_uart
remote
control
imu
5ms pit
```

主循环当前做：

```text
power_check_poll
kart_steer_abs_update
若速度环关闭则 kart_remote_poll
power_sync
kart_debug_uart_poll
5ms delay
```

5ms 中断当前做：

```text
kart_imu_update
kart_control_speed_update
```

这个结构保证后轮 duty 同一时刻只有一个写入源：速度环使能时由中断控制，速度环关闭时交给遥控/停机逻辑。

## 已解决

- `kart_steer_abs_update()` 已进入主循环，转向 raw 不再只在 init 读取一次。
- VOFA 通道已从 5 路扩到 7 路，新增转向 raw 和 center_delta。
- VOFA RX 链路已验证，`t/p/i/d/e` 命令可进入 MCU 并修改参数。
- `kart_remote.c` 不存在不是缺文件，遥控实现写在 `kart_power.c`。

## 待做

2. 修硬件：转向驱动/主板电源受损部分。
3. 验证转向绝对编码器飞线或 v2 修板后 raw 是否稳定。
4. 右后编码器做 `r_ab` 或等效 GPIO 电平实验，区分硬件/定时器问题。
5. 拆分左右后轮独立速度环，避免平均速度掩盖单轮故障。

7. 写 yaw 外环：`yaw_ref - yaw_now -> steer_target`。
8. 路径记录和回放。
9. 科目一状态机。

## 里程碑

### M1 上电自检

- 串口能输出启动信息。
- 三路电机保持停止。
- VOFA 能显示关键状态。

### M2 三路电机开环

- 架空测试。
- 每次只测一路。
- 正负 5% PWM 验证方向。
- 停止命令必须立即生效。

### M3 编码器

- 左后 TIM2 已正常。
- 右后 TIM5 待排查。
- 车辆向前时左右累计距离应同号。

### M4 转向绝对编码器

- 先修硬件 MOSI/CS。
- raw 范围 `0~4095`。
- 不动时抖动小。
- 记录中位、左右软限和是否跨 0。

### M5 IMU yaw

- 静止标定。
- yaw reset。
- 短时漂移可接受。
- 不依赖磁力计。

### M6 底盘闭环

- 后轮速度环。
- 前轮角度环。
- yaw 外环。
- 地面低速直行前必须完成停机测试。

### M7 路径记录与回放

## 当前禁止项

- `e0` 停不住未定位前，禁止继续大电流通电调速度环。
- 转向硬件修复前，禁止做转向闭环。
- 编码器方向未确认前，禁止地面闭环。
- 无日志输出时，禁止调 PID。
