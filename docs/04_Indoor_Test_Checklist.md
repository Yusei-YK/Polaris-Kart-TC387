# 卡丁室内测试清单

本文档用于室内低风险验证。任何地面自动运行前，必须先完成悬空测试和停机测试。

## 0. 测试通用规则

- 车轮第一次转动必须悬空。
- 电机第一次测试只用 5% PWM 或更低。
- 每次只测一个模块。
- 软件默认 `enable = 0`，必须手动进入测试模式才允许输出。
- 手边必须有断电方式。
- 不要在未知方向时闭环。
- 不要跳过日志记录。

每项测试都记录：

```text
日期:
固件版本:
电池电压:
测试模式:
现象:
是否通过:
问题:
处理:
```

## 1. 编译和上电自检

目标：确认工程能运行，不输出电机。

检查项：

- ADS 编译无错误。
- 上电后串口有启动信息。
- 屏幕或串口显示当前模式。
- 三路电机 PWM 为 0。
- 三路 DIR 不频繁抖动。
- 系统没有卡死或 Trap。

通过标准：

- 连续上电 5 次，启动信息稳定。
- 所有电机不转。

## 2. 传感器静态显示

目标：确认主要传感器能被读到。

显示内容：

- IMU yaw。
- IMU gyro z。
- 左编码器 delta。
- 右编码器 delta。
- 前轮绝对值编码器 raw。
- 当前模式。
- fault 标志。
- enable 标志。

通过标准：

- 静止时编码器 delta 接近 0。
- 静止时 yaw 缓慢变化或基本不变。
- 前轮绝对值编码器 raw 在不转动时稳定。

## 3. 三路电机开环测试

目标：确认 DIR+PWM 输出正确。

步骤：

1. 架空车辆。
2. 进入 `MODE_WHEEL_TEST` 或 `MODE_STEER_TEST`。
3. 只使能一路电机。
4. 输出 `+5%` PWM。
5. 停止。
6. 输出 `-5%` PWM。
7. 停止。
8. 换下一路。

记录：

- 转向电机正方向。
- 左后轮正方向。
- 右后轮正方向。
- 是否有异常声音。
- 驱动是否发热。
- nFAULT 是否触发。

通过标准：

- 三路能单独转。
- 停止命令能立即停止。
- 正负方向可通过 sign 宏修正。

## 4. 编码器方向测试

目标：确认车向前运动时左右编码器同号。

步骤：

1. 电机保持 disable。
2. 手推左后轮正转。
3. 观察左编码器 delta。
4. 手推右后轮正转。
5. 观察右编码器 delta。
6. 整车向前推 1 米。
7. 观察左右累计距离。

通过标准：

- 车辆向前时左右累计距离都为正。
- 左右距离量级接近。
- 如果反号，只改底层 `KART_LEFT_ENCODER_SIGN` 或 `KART_RIGHT_ENCODER_SIGN`。

特别检查：

- 右轮 TIM5 如果无法通过 `encoder_quad_init()` 初始化，要停止后续速度闭环测试，先解决编码器方案。

## 5. 前轮绝对值编码器测试

目标：确认 SPI3 读数可用。

步骤：

1. 车辆静止。
2. 打印 raw `0~4095`。
3. 手动向左打满。
4. 手动回中。
5. 手动向右打满。
6. 记录三个 raw 值。

通过标准：

- raw 值在 `0~4095` 范围内。
- 转动时连续变化。
- 不转动时抖动很小。
- 左右方向能判断。

后续需要记录：

- 中位 raw。
- 左软限 raw。
- 右软限 raw。
- 是否跨过 0/4095。

## 6. IMU yaw 测试

目标：确认 yaw reset 和方向正确。

步骤：

1. 静止上电。
2. 等待 IMU 初始化。
3. 调用 yaw reset。
4. 观察 yaw 接近 0。
5. 车身左转约 90 度。
6. 车身右转回原方向。

通过标准：

- reset 后 yaw 接近 0。
- 转动方向符合定义。
- 30 秒静止漂移可接受。

注意：

- 不要依赖磁力计。
- 如果 yaw 方向反了，只在 IMU wrapper 中处理，不要让上层状态机到处取反。

## 7. 转向角闭环测试

目标：让前轮能自动回到目标角度。

前提：

- 前轮绝对值编码器已通过。
- 转向电机正反方向已确认。
- 机械软限已记录。

步骤：

1. 架空前轮。
2. 目标角设为中心。
3. 手动轻推前轮离开中心。
4. 观察是否回中。
5. 小范围设置 `+5 deg`、`-5 deg`。

通过标准：

- 不震荡到机械限位。
- 不越调越偏。
- 超过软限会停止或限幅。

## 8. 左右后轮速度闭环测试

目标：悬空验证速度闭环。

前提：

- 编码器方向正确。
- 电机方向正确。

步骤：

1. 架空后轮。
2. 左右目标速度设为很低。
3. 观察左右 PWM、速度反馈。
4. 目标速度逐步增加。
5. 目标速度回到 0。

通过标准：

- 速度能跟随目标。
- 停止时 PWM 回到 0 或安全刹车值。
- 左右轮不会一个正转一个反转。

## 9. 低速地面直行

目标：验证基本底盘能直走。

前提：

- 转向闭环通过。
- 左右速度闭环通过。
- 急停可用。

步骤：

1. 地面空旷区域。
2. 目标速度很低。
3. 目标 yaw 固定 0。
4. 前进 1 米内停车。

通过标准：

- 车辆基本直行。
- 停车可靠。
- 日志中 yaw 误差、转向目标、左右速度可解释。

## 10. 路径记录

目标：记录 `distance-yaw-speed-event` 路径表。

步骤：

1. 进入 `MODE_PATH_RECORD`。
2. reset yaw 和距离。
3. 推车或极低速行驶一小段。
4. 停止记录。
5. 输出路径点数量和前几个点。

通过标准：

- distance 单调增加。
- yaw 符合运动方向。
- event 能手动插入或自动插入。

## 11. 悬空路径回放

目标：不落地先验证路径查询和目标输出。

步骤：

1. 架空车辆。
2. 进入 `MODE_PATH_REPLAY`。
3. 不允许高速 PWM。
4. 查看 `yaw_ref`、`speed_ref`、`steer_target`。

通过标准：

- 路径查询不会越界。
- 到路径末尾会进入 STOP。
- 输出有合理限幅。

## 12. 纸杯/胶带模拟绕桩

目标：低速验证科目一状态切换。

步骤：

1. 用纸杯或胶带模拟锥桶区域。
2. 速度限制在低速。
3. 只跑很短距离。
4. 观察状态机是否按事件切换。

通过标准：

- `WAIT_START -> FORWARD_REPLAY -> SLOW_FOR_PARK` 等状态清楚。
- 任何异常进入 `KART_FAULT` 或 `KART_STOP`。
- 不出现高速突然转向。

## 13. 禁止项

以下情况禁止地面自动运行：

- 编码器方向未确认。
- 前轮角度未确认。
- 转向闭环未通过。
- 电机 sign 未确认。
- 没有停机方式。
- 日志没有输出。
- 电池电压异常。
- nFAULT 或驱动异常未解释。
