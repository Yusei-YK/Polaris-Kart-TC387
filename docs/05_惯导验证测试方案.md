# IMU660RA + odom 验证

> 转向内环封板后再执行。本文是未来测试入口，不代表当前任务。

## 已知配置

- IMU：IMU660RA，SPI0，200Hz 更新。
- 上电标定：静置 1s，再采 300 次零偏，整段约 2.5s；期间不要碰车。
- VOFA：UART1，115200，20 通道 JustFloat。
- 主要通道：ch2 yaw，ch11 路程，ch12 x，ch13 y，ch14/15 左右累计脉冲。
- `z` 只清编码器和 odom，不会把 IMU yaw 清零。
- 暂时观察原始 yaw；现有五点算术平均跨 ±180° 会出错，修好前不用它做闭环。

## 测试顺序

### 1. 静止漂移

车静止 60 秒，记录 ch2 起点、终点和最大摆动。

通过标准先不写死：先拿到三组实测，再决定是否需要继续调零偏或滤波。

### 2. 转向符号

记住当前 ch2 作为基线：

- 原地左转约 90°，记录 yaw 变化方向。
- 回到起点，再原地右转约 90°。
- 根据实际结果确认 `KART_ODOM_YAW_SIGN`，不要凭文档猜。

### 3. 编码器距离

执行 `z`，直线推车 3～5m：

- ch11 应接近实测距离。
- ch14、ch15 应同向增长且数量接近。
- 用 `实测距离 / 平均脉冲增量` 更新 `KART_ODOM_ENC_PULSE_TO_M`。

### 4. L 形轨迹

执行 `z`，记录当前 yaw 基线，然后：

1. 直行约 3m。
2. 左转约 90°。
3. 再直行约 3m。

检查 ch12/ch13 是否形成方向正确的 L，而不是镜像、直线或乱飘。

## 通过之后

只有距离系数、yaw 符号和静止漂移都可接受，才进入航向外环和路径录制。否则继续修 IMU/odom，不拿回放代码掩盖基础误差。
