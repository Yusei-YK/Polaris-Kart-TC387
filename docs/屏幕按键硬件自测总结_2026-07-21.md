# 屏幕和按键硬件自测总结

> 完成日期：2026-07-21
> 任务：验证新换的 IPS200 屏幕 + 旋钮编码器 + 五向按键硬件

## 硬件确认

### 屏幕（IPS200）
- **接口类型**：SPI（不是并口）
- **丝印标注**：BLK/CS/DC/RST/SDA/SCL/VCC/GND（第二排全是 NC）
- **引脚连接**（软件 SPI）：
  - SCL = P02.8
  - SDA = P20.3
  - DC = P15.0
  - RST = P15.1
  - CS = P00.12
  - BLK = P33.9

### 按键板连接（H1 12针排针）
- **旋钮编码器**：A=P11.2, B=P11.3, SW=P20.0
- **五向按键**：
  - UP = P33.11（硬件与 P21.6 短路，按物理 UP 或 LEFT 都会触发）
  - DOWN = P20.6
  - LEFT = P33.4（实际是 SW2.6）
  - RIGHT = P21.7
  - MID = P20.7（SW3 独立按键）
- **所有按键**：外部上拉电阻 4.7kΩ 到 U4.5（电源管理芯片输出）

## 关键修改

### 1. 屏幕驱动（zf_device_ips200.h）
```c
#define IPS200_USE_SOFT_SPI             (1)         // 改用软件 SPI
#define IPS200_SCL_PIN                  (P02_8)     // 对应硬件
#define IPS200_SDA_PIN                  (P20_3)     // 对应硬件
#define IPS200_RST_PIN_SPI              (P15_1)
#define IPS200_DC_PIN_SPI               (P15_0)
#define IPS200_CS_PIN_SPI               (P00_12)    // 对应硬件
#define IPS200_BLk_PIN_SPI              (P33_9)     // 对应硬件
```

### 2. 引脚定义（kart_hw_test.h）
```c
/* 旋钮引脚 */
#define KART_KNOB_A_PIN         (P11_2)
#define KART_KNOB_B_PIN         (P11_3)
#define KART_KNOB_SW_PIN        (P20_0)             // 实测是 P20.0，不是 P20.6

/* 5 向按键引脚（硬件 UP/LEFT 短路，重新映射）*/
#define KART_KEY_UP_PIN         (P33_11)            // 与 P21.6 短路
#define KART_KEY_DOWN_PIN       (P20_6)             // 实测是 P20.6，不是 P20.0
#define KART_KEY_LEFT_PIN       (P33_4)             // 实测
#define KART_KEY_RIGHT_PIN      (P21_7)
#define KART_KEY_MID_PIN        (P20_7)             // 实测
```

### 3. 旋钮解码算法（kart_hw_test.c）
采用 **AB 双相 4 倍频解码**（最简单可靠）：
```c
/* 检测 AB 任意一相变化，根据另一相当前状态判断方向 */
if(a != knob_a_last) {
    if(a == 1 && b == 0)      knob_count++;  // A 上升 B=0 → 顺时针
    else if(a == 0 && b == 1) knob_count++;  // A 下降 B=1 → 顺时针
    else if(a == 1 && b == 1) knob_count--;  // A 上升 B=1 → 逆时针
    else if(a == 0 && b == 0) knob_count--;  // A 下降 B=0 → 逆时针
}
// B 相同理
```

### 4. GPIO 配置
- **旋钮 A/B/SW**：`GPI_PULL_UP`（内部上拉）
- **五向按键**：`GPI_FLOATING_IN`（浮空输入，避免与外部上拉冲突）

## 硬件问题

1. **UP 和 P21.6 短路**：硬件缺陷，按 UP 或物理 LEFT 都会触发 UP
2. **引脚标注错误**：
   - 网表标 P20.6 = 旋钮 SW，实际是 DOWN 按键
   - 网表标 P20.0 = DOWN 按键，实际是旋钮 SW

## 使用方法

1. 打开硬件自测：`cpu0_main.c` 第 21 行改为 `#define KART_HW_TEST (1)`
2. Build + 烧录，上电看到：
   - 红→绿→蓝彩条（各 0.5s）
   - "HW TEST" 标题
   - 旋钮计数 + 五向按键实时状态（1=松开，0=按下）
3. 测试完成后改回 `#define KART_HW_TEST (0)`，恢复正常主循环
