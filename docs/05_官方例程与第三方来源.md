### TC387 官方例程的接口事实

官方 TC387 Demo 当前给出的 TLD7002 通信配置为：

```text
UART_1
baud: 2,000,000
MCU TX: P33.12 -> 模块 RX
MCU RX: P33.13 <- 模块 HSLI_L
GPIN0: P32.4
SYNC: P20.9，ERU 下降沿中断
```

官方 7x15 点阵例程另使用 7 路行选：`P20.0`、`P20.3`、`P00.8`、`P33.9`、`P14.4`、`P14.5`、`P14.6`。

### 当前 SmartCar 原理图结论

主板与灯板原理图已经补齐。当前板卡实际接口为：

```text
UART0, 2 Mbps
P14.0 -> 灯板 RX
P14.1 <- 灯板 HSLIL
P20.8 / P20.9 / P20.10 -> A0 / A1 / A2
P33.8 -> ROW_EN（高电平使能）
```

灯板通过 74HC238 把三位地址译码成 `SR0~SR6`，与官方七路 GPIO 直接行选不同，扫描函数必须适配。主板接口为 20 针、灯板接口为 24 针且同针号定义不一致，已经确定使用杜邦线逐根飞线，不能使用直通排线。

计划补充飞线：

```text
P10.2 / ERU_CH2_REQ2 <- 灯板 SYNC（H1-22）
P11.6               -> 灯板 GPIN0（H1-21）
```

`P10.2/P11.6` 原预留为无线 RTS/RST，当前无线程序未使用这两路，但后续不得与灯板同时启用。UART0 默认调试串口仍与灯板冲突，必须在底层接入时迁移或关闭。接口事实已经明确，剩余工作是驱动适配、ADS 编译、飞线和上板验证。

### 比赛要求边界

第 21 届卡丁快跑科目细则列出左转、右转、远光、近光、雾灯、双闪、车内照明和雨刷八种命令，并允许独立 LED 屏使用不同图案表示任务；雨刷也允许使用灯表示。规则允许 TLD4020 或其它英飞凌 TLD 系列芯片，因此本项目采用 TLD7002 符合该条文字要求。规则给出的灯光图案属于示例，没有规定必须逐像素复刻。因此 `kart_light` 当前八类互不混淆的图案满足逻辑阶段需求，最终亮度、方向和可辨识度留待上板检查。
