## 硬件/底层排查结论摘要（详见 Kart_TC387/docs/排查记录.md）

1. **转向绝对值编码器读不出** → 已定位：PCB 把 MOSI 布到 P23.1（TC387 SPI4 非法 MOSI 脚）。v1 飞线修，v2 对调焊盘。代码侧 `board_pins.h` 配置本身正确，协议是逐飞官方驱动的忠实移植。
2. **右后编码器完全没数** → 已定位安装断裂并换件，接线问题待排除；软件链正常，TIM5（GPT1 计数模式）与左后 TIM2（GPT2 真正交）本质不同但不会"完全没数"，指向硬件。用 CSV 的 `r_ab` 字段做架空转轮实验区分硬件/软件。
3. **第二版 PCB** → 底盘核心引脚 v1=v2 不变；无线串口 UART2→UART1（P33.12/13）需改代码；屏幕改 8 位并口（全 GPIO，无需改底盘引脚）；转向编码器 MOSI/CS 焊盘对调 v2 定版前必改。
4. **库差异** → 代码用 `SPI_4` 必须链 TC387 库（TC264 库无 SPI_4）。当前工程已确认链 TC387 库。
