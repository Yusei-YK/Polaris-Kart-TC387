# 代码规范

面向 `Kart_TC387/` 工程。参考 TopSpeed 的分层做法，按本工程实际情况裁剪。

目的只有一个：改一处就够，不用翻遍二十几个头文件。

---

## 一、目录与分层

2026-08 按 TopSpeed 的做法把用户代码从 `user/` 平铺挪进 `code/` 分层目录。
`user/` 现在只留启动与中断相关的东西，业务逻辑一律不放在那里。

| 目录 | 职责 | 文件 |
|---|---|---|
| `code/Kart_Config` | 标定量、方向符号、引脚 | `kart_calib.h` `board_pins.h` |
| `code/Kart_Driver` | 直接碰硬件 | `kart_power` `kart_encoder` `kart_steer_abs` `kart_horn` `kart_flash` |
| `code/Kart_Algo` | 无硬件依赖的纯计算，可在 PC 上单测 | `kart_calc` `kart_pid` |
| `code/Kart_App` | 状态估计与闭环、遥控/语音/灯板 | `kart_imu` `kart_odom` `kart_control` `kart_steer_ctrl` `kart_remote` `kart_voice` `kart_light` |
| `code/Kart_Decision` | 决定"现在该干什么" | `kart_mission` `kart_menu` `kart_params` `kart_motion` `kart_record` `kart_playback` |
| `code/Kart_Debug` | 只读观测与自检 | `kart_debug_uart` `kart_hw_test` `kart_traj_view` |
| `code/Kart_TPL` | 第三方/器件驱动，尽量不改 | `TLD7002_driver/` `zf_device_tld7002` `zf_device_dot_matrix_screen` |
| `user/` | 启动、中断向量、核间调度 | `cpu0~3_main` `isr` `isr_config` `kart_multicore` |

`code/kart_include.h` 按这个顺序索引全部模块头，兼作分层说明。

依赖方向只许从上往下：`Decision → App → Algo/Driver → Config`
（决策可以调控制，控制不许回调决策）。

### include 不写目录前缀

`code/Kart_*` 每个目录都进了编译器 `-I` 搜索路径，所以 `#include` 只写文件名。
以后再挪目录，改 `-I` 列表就行，不用回头改几十条 include。

## 二、标定量集中在 kart_calib.h

换齿轮、换编码器、换轮子、换遥控器之后**只改这一个文件**。

放什么：车辆几何、电机与编码器极性、编码器尺度、转向零位与硬限位、
遥控通道端点、各控制环反馈符号。

不放什么：PID 增益、限幅、阈值、状态机参数。那些是调出来的不是量出来的，
留在各自模块头文件，现场靠菜单（`kart_params`）改。

### 派生量不要手改

标了"派生"的宏由实测值算出来，例如转向软限位由三个硬限位 raw 算：

```
硬限位 raw (1248 / 3176 / 中位 164)
  → 行程 TRAVEL_L/R
  → 软限位 DELTA_LIMIT_L/R          (±1064)
  → 航向外环上限 HEAD_OUTMAX
  → 满舵半径 MIN_RADIUS_M           (1.39m)
```

重标转向只改那三个 raw，下游全部自动跟随。手改派生值会让两处对不上——
2026-07-28 那次"复刻切内侧锥桶"就是外环上限（1000）比软限位（1103）小，
暗中削掉了最后 100 计数打角。

### 一个值只许有一处定义

搬走之后原位置留一行指路注释，不留第二份定义：

```c
/* 后轮减速比 KART_REAR_GEAR_RATIO → kart_calib.h 第三节 */
```

同一个物理量在两个文件里各写一遍，早晚会只改一处。

## 三、符号宏

所有"越纠越歪"类故障都收敛到 `kart_calib.h` 第六节的几个符号宏。
现象一律是正反馈发散：车不是慢慢修回来，而是一路怼到限位或越走越斜。

纪律：**一次只翻一个，翻完必须实车确认**。有几个符号是多科目共用的
（`KART_REV_HEAD_SIGN` 同时管科目一/二/四的倒车），赛场上猜着乱翻会连带
搞坏别的科目。

区分两类，不要混：
- 接线/极性反了 → 第二节（`*_MOTOR_SIGN` / `*_ENCODER_SIGN`）
- 控制环反馈反了 → 第六节（`*_LOOP_SIGN` / `*_YAW_SIGN`）

## 四、头文件

- 只放宏、类型、`extern` 声明和函数原型，不放函数实现和变量定义
- 一律带 `#ifndef XXX_H_` 头卫
- `#include` 按 库 → 标定 → 本层 → 下层 排，每个非显然的 include 注明理由：

```c
#include "kart_calib.h"    /* KART_REAR_GEAR_RATIO、脉冲↔m/s 换算 */
#include "kart_power.h"    /* KART_POWER_MAX_DUTY:下方 OUTMAX 要用 */
```

- 模块头顶部注释写清三件事：这个模块干什么、**调用节拍放哪**（主循环还是
  5ms 中断）、量纲。节拍写错会吃到上电那帧死数据，这类 bug 很难查。

## 五、注释

写**为什么**，不写做了什么。代码本身已经说了做什么。

有价值的注释是这三类，其余尽量少写：

1. **改动依据**：带日期 + 数据/物理量。例如速度斜坡 `1.5 → 0.4`，
   注释算出 1.5 相当于 22 m/s²，而整车只有 3.4 m/s²、抓地极限 5~7 m/s²，
   旧值比车能做到的快 5~9 倍，等于限幅从未生效。这段注释省掉的是下一次
   重新踩同一个坑。
2. **已推翻的判断**：标明作废，别让后人再走一遍。
   例：曾以为航向环增益要乘 57.3（deg/rad），是错的，已撤回。
3. **安全约束**：为什么必须是这个顺序、这个上限。
   例：开环支路必须排在 `!enable` 检查之后，顺序反了遥控急停就失效。

反面：`/* 设置速度 */` 这种，删掉信息量不变。

## 六、参数分三档

| 档 | 载体 | 改法 | 适用 |
|---|---|---|---|
| 标定 | `kart_calib.h` | 改代码重烧 | 换硬件才动 |
| 出厂默认 | 各模块头文件宏 | 改代码重烧 | 调好就冻结 |
| 现场可调 | `kart_params` + 菜单 | 车上按键 | 每次比赛要动 |

比赛现场没有上位机，凡是**可能在场地上要改**的值必须进 `kart_params`。
2026-07-28 加菜单在线调速就是被这件事逼出来的。

注意 `kart_params_init` 校验 `page_buf[1] == KART_PARAM_MAX`：**增删参数会
让整张已存参数表作废**，现场调好的值全部回到出厂默认。赛前不要动参数表长度。

## 七、命名

- 模块前缀 `kart_`，逐飞设备驱动保持 `zf_device_` 前缀
- 宏全大写 `KART_<模块>_<含义>`，函数小写 `kart_<模块>_<动作>`
- 单位进名字或注释，不靠猜：`_M`（米）`_MS`（m/s）`_DIST`（米）
  `_RAW`（编码器原始计数）`_DELTA`（相对中位计数）
- 内部状态用 `static`，只用 `extern` 暴露必要的结构体

## 八、改动纪律

本机没有 TriCore 工具链，编译烧写在 AURIX Studio 做。所以改完必须自查：

1. 搬宏之后 `grep` 确认全工程只有一处定义
2. 确认每个用到该宏的 .c 仍能通过 include 链解析到
   （链路：`xxx.c` → `xxx.h` → `board_pins.h` → `kart_calib.h`）
3. 派生式改完手算一遍，和原硬编码值对上
4. 跑 `python tools/check_subject2.py`，要 ALL PASS
5. 新增 .c **不用**手工登记。`.cproject` 用的是整工程 `sourceEntries`
   （只排除 `libraries/` 里几项），源文件自动发现，`Debug/*.mk` 是 AURIX Studio
   生成的产物，别手改——下次 Clean 就被覆盖。
6. 新增**目录**要把它加进 `.cproject` 里 Debug 配置的编译器 `-I` 列表
   （`...compiler.tasking.include.paths` 那段 `listOptionValue`），
   否则同目录之外的文件 `#include "xxx.h"` 找不到头。
7. 挪过目录之后在 AURIX Studio 里 **Clean + Rebuild**，别增量编
   ——旧的 `.o` 和 `.d` 还挂在老路径上。

赛前改动额外一条：**能不动就不动**。整齐不值得拿一次完赛去换。
